# Reference bar for the sirven install clip (and all future demos)

Source: Jose's reference video (ElevenAgents Architect, 1:07, 720p). Note: "the bottom has helper sections to show structure .. this is the standard for demos from now on."

## Style rules extracted
- Light, minimal, calm. Lots of negative space. One idea on screen at a time; one animation at a time; no fast cuts.
- Subtle background texture: faint grids, dotted fields, rounded-square lattice. Never busy.
- Soft gradient wash (pink/blue blur) behind a floating UI card as the hero object.
- A single recurring hero object carries the story (their chat-input card; ours: the terminal card running the curl install).
- Real interface structure shown as clean floating panels (their Steps/Tools blocks; ours: the install plan output, the two setup questions, the level summary) - cropped, elevated, never a raw full-screen capture.
- Typography-led transition beats on plain backgrounds between sections (short phrases, generous spacing).
- Helper sections at the bottom of the frame show structure/progress (their brand lockup strip; ours: a slim bottom strip marking the current step: paste -> answer -> done).
- Brief human/relief beat mid-video (their photo grid; ours optional: the "while you sleep" moment).
- Ends on the brand lockup, calm. Pacing: ~1 minute total. Sound optional; it must read silently.

## Applied to the sirven install clip storyboard
1. Paste beat: terminal card on gradient wash, command types in: curl -fsSL cli.sirven.xyz | sh. Bottom strip: step 1 of 3.
2. Two questions beat: the two setup questions appear one at a time, answered with defaults visible. Bottom strip: step 2.
3. Done beat: the complete plan summary flashes as a structured panel (levels, audit on, nothing hidden), then "setup in seconds" typography beat, sirven lockup. Bottom strip: step 3.
Real prompts captured with VHS from the real installer; composed in Remotion with Remotion Bits + the GSAP adapter.
